## 1. Дымовое тестирование
- [ ] Все контейнеры сервисов подняты

- [ ] Через Gateway доступен API (без ответов 500)
- [ ] Генерация тестовых карт работает
- [ ] Список карт возвращается

## 2. Критический путь
### 2.1 Подготовка
- [ ] Сгенерированы тестовые карты для позитивных и негативных проверок

### 2.2 Happy path
- [ ] Транзакция уходит через Gateway
- [ ] Switch маршрутизирует по BIN к Authorization
- [ ] Authorization возвращает APPROVED
- [ ] Средства резервируются в Card Management
- [ ] Транзакция видна в логах и на дашборде

### 2.3 Отказы в авторизации
- [ ] Отказ при несуществующей карте
- [ ] Отказ при INACTIVE / BLOCKED / EXPIRED
- [ ] Отказ при превышении дневного или месячного лимита
- [ ] Отказ при недостатке баланса
- [ ] Код ответа / причина отказа проходят по цепочке до клиента

### 2.4 Согласованность после операции

- [ ] После APPROVED баланс и usage согласованы с суммой
- [ ] После DECLINED баланс не списан
- [ ] Повторный запрос с тем же контекстом не ломает целостность данных
